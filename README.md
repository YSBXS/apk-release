# apk-release

抓取市面上流行的影视壳子，免费分享给大家使用。

这里只做搬运和整理：安装包来自各软件作者的官方发布渠道，自动同步，不修改、不植入任何东西。

## 下载

点上方 **Releases**，选最新一条，下载需要的文件即可。

- 文件名统一为「软件名【版本号】」，同一软件的历史版本都会保留，需要旧版可以往前翻。
- 更新检查约每 6 小时一次（北京时间 08:00、14:00、20:00、次日 02:00），上游有新版就会自动发布。
